# SpaceLean Platform Overview

SpaceLean is an AI-native construction scheduling platform that parses 3D BIM models (IFC/Revit) into 4D critical path schedules. It eliminates manual Primavera P6 linking and predicts delay risks using a 1,000-simulation probabilistic Monte Carlo engine.

## Core Capabilities
- **IFC / Revit BIM Parsing**: Converts geometry into trade task dependencies in under 60 seconds.
- **Critical Path Prediction**: Scores delay probability with 94% accuracy.
- **Self-Healing CPM**: Dynamically recalculates downstream float when site delays occur.
