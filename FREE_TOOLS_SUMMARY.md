# SpaceLean Free Tools Overview

A short summary of the 6 recommended free online tools designed to drive lead generation, organic traffic, and SEO/GEO authority for SpaceLean.

---

### 1. AI Construction Schedule Generator
* **Purpose**: Converts natural language project descriptions (e.g., building type, size, start date) into structured baseline construction schedules, Work Breakdown Structures (WBS), and interactive Gantt charts that users can edit and export directly to Primavera P6 (XER) or MS Project (XML) formats.

### 2. Construction Critical Path Method (CPM) Calculator
* **Purpose**: An interactive math solver where planners input tasks, durations, and predecessors, and the tool dynamically runs forward/backward pass algorithms to compute Early/Late starts, finishes, total float, and highlights the project's critical path on a visual network graph.

### 3. Construction Crew Productivity & Trade Stacking Calculator
* **Purpose**: Helps contractors measure site density and labor efficiency loss by mapping spatial constraints and active crew counts to standard MCAA/CII trade stacking curves, showing estimated financial impacts of congested workforces.

### 4. BIM IFC File Health Checker & Metadata Audit Tool
* **Purpose**: A client-side metadata check tool (privacy-first via WebAssembly) where VDC/BIM managers upload `.ifc` models to scan if standard classification codes (OmniClass, UniFormat) and spatial hierarchy properties required for scheduling integrations are complete.

### 5. Construction Risk & Delay Analyzer (Monte Carlo Simulation)
* **Purpose**: A browser-side probability simulator where users input optimistic, realistic, and pessimistic task durations to run Monte Carlo iterations and plot a project completion S-Curve, showing the likelihood of finishing by a specific deadline.

### 6. Primavera P6 XER to MS Project XML Converter
* **Purpose**: A secure utility that parses Oracle Primavera `.xer` files inside the browser (100% client-side) and converts them into MS Project XML or Excel CSV formats, helping subcontractors open and align schedules without requiring expensive licensing.
